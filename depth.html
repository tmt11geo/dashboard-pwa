What this experiment can do

Move slowly and compare nearby objects with the background. Start at 224 px; stop before changing detail or compute mode. Auto prefers WebGPU and uses CPU when no GPU adapter is available. If GPU initialization fails, choose CPU / WASM and retry. TFJS WebGL is the default option, fixed at 224 × 224 with padding to preserve the full view. It requires WebGL in a worker and fails visibly if unavailable. CPU mode may be much slower. Pause depth keeps the camera open; One depth frame processes a single fresh frame while paused. Stop & release, hiding the page, or leaving it stops the camera and terminates the model worker.

The depth colours are normalized separately for each image: they indicate nearer and farther surfaces, not distances in metres. The 3D relief back-projects that estimated shape using an assumed 55° horizontal field of view and an arbitrary inverse-depth scale. It replaces the previous frame; it is not an accumulated point-cloud map, SLAM, or saved-map localization. Thin objects, sky, reflections and unfamiliar scenes can be wrong. The camera feed is live; depth and relief show the latest completed inference and can lag.

Processing runs locally in a dedicated worker with at most one frame in flight. No video, frames or timing data are uploaded. The last result stays in memory for inspection until restart or page close. ONNX model weights download from Hugging Face; TFJS model weights download from this site. Runtime code and WASM download from jsDelivr. Internet is required for uncached downloads. This page uses the existing Tactical theme and PWA identity.
