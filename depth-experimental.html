Scan tips & saving

Use a textured, stationary scene. Move slightly sideways, keep most of the previous view visible, then hold still. Keep the phone in the same orientation. Approximate shape, arbitrary scale; alignment may drift or reject views.

What this experiment can do

Move slowly and compare nearby objects with the background. Start at 224 px; stop before changing detail or compute mode. Auto prefers WebGPU and uses CPU when no GPU adapter is available. If GPU initialization fails, choose CPU / WASM and retry. TFJS WebGL is an explicit experimental option, fixed at 224 × 224 with padding to preserve the full view. It requires WebGL in a worker and fails visibly if unavailable. CPU mode may be much slower. Pause depth keeps the camera open; One depth frame processes a single fresh frame while paused. Stop & release, hiding the page, or leaving it stops the camera and terminates the model worker.

The depth colours are normalized separately for each image: they indicate nearer and farther surfaces, not distances in metres. The 3D relief back-projects that estimated shape using an assumed 55° horizontal field of view and an arbitrary inverse-depth scale. Ordinary depth mode replaces the previous frame. Guided scan instead matches shared image detail and relative-depth geometry to accumulate accepted views. It uses an assumed 55° field of view along the longer image dimension, rejects uncertain alignment, and retains earlier points. It is an approximate local reconstruction with no loop closure or metric calibration; it can drift, especially on moving or reflective surfaces. Saved scenes can be inspected but cannot resume tracking. Thin objects, sky, reflections and unfamiliar scenes can be wrong. The camera feed is live; depth and relief show the latest completed inference and can lag.

Processing runs locally in a dedicated worker with at most one frame in flight. No video, frames or timing data are uploaded. The current scan stays in memory until Clear or page close; use Save relief file to keep it. Files contain coloured scene geometry; no camera images are included. ONNX model weights download from Hugging Face; TFJS model weights download from this site. Runtime code and WASM download from jsDelivr. Internet is required for uncached downloads.
