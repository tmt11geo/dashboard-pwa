How to use

Tap a box or an object button to lock it. YOLO stops completely while a lightweight visual tracker follows that object. Use Release / scan to restart object detection. Arrows beside the locked box show which direction to move the device to centre the object in the viewfinder crosshair. The lock reads CENTRED inside the small centre zone.

If the object disappears near an edge, an amber indicator shows its likely exit side or corner and YOLO automatically searches for it for up to 30 seconds. A matching label and visual appearance, confirmed in two detections, return the page to locked tracking with YOLO stopped. Similar objects may still be confused. If it disappears elsewhere, the page reports a lost lock. Exit direction is an estimate from the last visible box, not off-screen sensing. Use Release / scan, then tap a detection to reacquire.

YOLO recognises 80 everyday object classes. The tracker follows the selected image patch, with YOLO stopped while the object remains locked. It can lose the lock with low texture, occlusion, fast movement, rotation or a large change of appearance. Tracking speed varies by phone and lighting.

Video is processed locally and is not recorded or uploaded. Starting downloads the YOLO model (~9 MB) from Hugging Face and ONNX Runtime from jsDelivr. Internet access is required for those downloads. Camera access needs HTTPS and browser permission. Leaving or hiding the page stops the camera; tap Open camera to resume.
