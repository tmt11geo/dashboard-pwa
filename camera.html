How to use

Without a YOLO label: tap Select area and drag a box around the object with a finger or mouse. You can pinch to zoom first or while in selection mode. Releasing a valid box returns to the full image and tracks that bitmap patch, with YOLO stopped. Cancel selection returns to normal scanning. If the selected area has too little detail, try a larger or more textured area. If a manual target leaves an edge, a background bitmap search looks for its saved appearance for up to 30 seconds. Three consistent, unambiguous matches restore the lock. The search checks the exit side first, then the full view at several sizes. YOLO stays stopped. Large rotations, changed appearance or similar-looking patches can prevent or confuse a match. Select area can replace the target at any time. YOLO-labelled targets keep their existing YOLO reacquisition.

Pinch the image to zoom (up to 8×), then drag to position the selection area. The + / − buttons also control zoom. YOLO scans only the visible zoomed area; full-view detections are cleared. Tap a box or an object button to return to the full image and follow only the selected object. Zoom controls are available while scanning. YOLO stops completely while a lightweight visual tracker follows that object. Use Release / scan to restart object detection. Arrows beside the locked box show which direction to move the device to centre the object in the viewfinder crosshair. The lock reads CENTRED inside the small centre zone.

For a YOLO-labelled object disappearing near an edge, an amber indicator shows its likely exit side or corner and YOLO automatically searches for it for up to 30 seconds. A matching label and visual appearance, confirmed in two detections, return the page to locked tracking with YOLO stopped. Similar objects may still be confused. If it disappears elsewhere, the page reports a lost lock. Exit direction is an estimate from the last visible box, not off-screen sensing. Use Release / scan, then tap a detection to reacquire.

YOLO recognises 80 everyday object classes. The tracker follows the selected image patch, with YOLO stopped while the object remains locked. It can lose the lock with low texture, occlusion, fast movement, rotation or a large change of appearance. Tracking speed varies by phone and lighting.

Video is processed locally and is not recorded or uploaded. Starting downloads the YOLO model (~9 MB) from Hugging Face and ONNX Runtime from jsDelivr. Internet access is required for those downloads. Camera access needs HTTPS and browser permission. Leaving or hiding the page stops the camera; tap Open camera to resume.
